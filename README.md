# RI6 — Calculadora simples

Calculadora de terminal feita em TypeScript para praticar classes, herança, encapsulamento e polimorfismo.

## Executar

```bash
npm install
npm run dev
```

## Operações

- Soma
- Subtração
- Divisão
- Potenciação
- Radiciação
- Bhaskara

A calculadora recebe os valores pelo terminal usando `readline`.
